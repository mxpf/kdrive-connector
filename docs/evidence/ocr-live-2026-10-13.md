# Synthetic live OCR acceptance — 2026-10-13

**Decision: accuracy gate failed; keep OCR disabled. No deployment.**

The signed-in Cloudflare dashboard showed Workers Free as the current plan.
Only fabricated pages were submitted, using the production byte-verification,
PDF parsing, rendering and OCR adapter with a fixture-backed kDrive client.
Cloudflare's REST API performed real inference. This did not test the production
Worker AI binding, production resource limits or an actual ChatGPT conversation.

must remain separate from visual transcription.

## Response contract and usage

Two initial diagnostic calls returned HTTP 200 but the adapter rejected the
nested model response. The fix unwraps `result.answer` and checks the observed
`finish_reason: "stop"`; direct answer objects remain supported. A normal stop
does not prove recognition completeness. All seven calls after the fix completed
with HTTP 200 and `stop`.

- Seven-case run: **202.9000 neurons**.
- Two diagnostic calls: **30.1545 neurons each**.
- Total for this session: **263.2091 neurons**, about 2.63% of the 10,000/day
  Free allocation. This excludes any other account usage.
- No automatic retries, fallback providers, account upgrade or deployment.

## Reproducible evidence

[Original seven-case report](ocr-live-2026-10-13.json) preserves fixture hashes,
extracted fields, transcripts, model envelopes, usage and timings. It contains
only synthetic content, with no credentials, account identity or private files.
Its original `forms` status checked labels only and must **not** be treated as a
visual accuracy pass. The updated fixture requires explicit checked/unchecked
marks; `test/pdf-ocr-acceptance.test.ts` replays all seven captured envelopes and
rejects the rotated, small-print and form cases without another model call.

The runner now exits nonzero on missing expected phrases as well as transport,
contract or stored-field failures. Manual review is still necessary for invented
content or omissions outside the expected phrases. Further work should test
orientation correction and bounded regions for small text against independent
fixtures before any OCR enablement is proposed.
